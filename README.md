# 温度ログ — GitHub Pages版 v1.1

タイムラプス動画から1分ごとの温度を抽出するWebアプリです。Pythonのインストールは不要。HTML/CSS/JavaScriptだけで動き、GitHub Pagesにそのまま公開できます。

## すぐ試す

ZIPを解凍し、`index.html` をChromeまたはEdgeで開いてください。動画を開く→時間設定→範囲指定→抽出→Excel保存の順で使えます。公開後はURLを開くだけです。ローカルファイルで開いた場合、ホーム画面追加・オフラインキャッシュは有効になりません。

1. 「動画を開く」でMJPEG形式のAVIを選択。
2. 撮影間隔10秒／コマ、抽出間隔1分を確認。
3. 提供されたTLC00000〜TLC00003には「この動画の検証済み範囲を使う」を使用。ファイル名・サイズ・コマ数が一致する場合のみ有効です。
4. 別の動画では目的の数字全体を少し余白を含めて左上→右上→右下→左下の4点で囲み、「各桁の位置を自動で合わせる」を実行。ほかの数字を範囲に入れないでください。
5. 判定枠が各数字に合っているか確認し、「温度を抽出する」。未調整なら抽出前に自動調整します。
6. 「Excelをダウンロード」。要確認の行は候補と画像を確認して温度を入力。

更新時はZIP内の全ファイルを既存リポジトリに上書きし、公開完了後に再読み込みしてください。タイトル横の **v1.1** が目印です。

## GitHub Pagesで公開

1. GitHubで新しい公開リポジトリを作成（例：`temperature-log`）。
2. ZIP内の**ファイルとvendorフォルダーをリポジトリ直下**にアップロード。`index.html` がリポジトリ直下に来るようにします。ZIPそのものを置くだけでは動きません。
3. Settings → Pages → Build and deployment → Source を `Deploy from a branch` にする。
4. Branch を `main`、フォルダーを `/(root)` としてSave。
5. 公開完了後、Pagesに表示されたURLを開く。

GitHub Pagesへの公開方法：https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

動画や実験結果をリポジトリへアップロードする必要はありません。アプリのファイルだけを公開します。認証情報、APIキー、外部APIは不要です。

## 時間の定義

先頭コマ＝実経過0秒、コマ番号×撮影間隔で換算。動画再生fpsは温度データの時間軸に使いません。10秒撮影なら6コマで1分。TLC00003では0〜34分の35件（0分を除外すると1〜34分の34件）になります。最後の208コマは34分40秒です。

撮影画像1枚が動画1コマに対応する、欠落・重複のない等間隔タイムラプスが前提です。撮影間隔の整数倍でない抽出指定はエラーにし、勝手に丸めません。

## 対応範囲

- **入力：MJPEG形式のAVI**。提供された4本を認識エンジンで検証済み。
- MP4や他のAVIコーデックは、このWeb版では未対応です。ブラウザの動画シークでコマ番号を推測せず、AVI内のJPEGコマを直接読み取ります。
- 固定カメラ・黄緑色の整数7セグメント、1〜8桁。斜めに写った表示を4点で補正。
- カメラ追跡、小数点、負数には未対応。
- 対象の位置が違う動画では専用設定を流用せず、4点を指定し直してください。
- 1GB以下の動画を対象にしていますが、端末のメモリによってそれ以下でも処理できない場合があります。大きい動画はPCでの利用を想定。
- 白い反射・点灯欠けなどでOKでも誤認する場合があります。研究用データとして使う前に確認してください。

動画・範囲・結果は端末内のメモリで処理します。サーバーへ送信しません。ページを閉じる前に結果や範囲設定を保存してください。ホーム画面追加は対応ブラウザで利用できます。初回オンラインで開いたアプリ本体のみをキャッシュします。

## Excel

「温度データ」「確認画像」「抽出条件」の3シート、編集可能な散布図付き。温度データのA列が実経過分、B列が温度。要確認の温度は空欄、認識候補と画像を記録します。候補を自動で確定値にはしません。

CSVも出力可能。CSVは数表のみで、画像やグラフは含みません。

## 検証

v1.1では、最大10コマの点灯領域から各桁の位置を検出して余白を除去します。複数コマは形状の位置合わせにのみ使用し、温度の平均化や補間はしません。抽出は6コマごとの実コマから行います。

提供動画を同じ認識エンジンで処理し、目視値と候補を比較しました（0分を含む）。

| 動画 | 抽出点 | 候補一致 | 要確認 |
| --- | ---: | ---: | ---: |
| TLC00000 | 1 | 1 | 0 |
| TLC00001 | 30 | 30 | 0 |
| TLC00002 | 29 | 29 | 9 |
| TLC00003 | 35 | 35 | 6 |
| 合計 | 95 | 95 | 15 |

TLC00000は4コマ（0〜30秒）のため0分の1点だけです。要確認の15点は候補が一致していても自動確定しません。この結果は提供動画で調整した結果であり、未知の動画に対する正解率ではありません。

公開中の旧版では、実際のブラウザ操作でTLC00001の30点すべてが要確認になる症状を再現しました。v1.1の検証はAVI解析・画像デコード・認識エンジンとJavaScript構文の確認です。修正版のブラウザ操作、Safari、PWAインストールは未検証で、公開後の確認が必要です。Excel出力は前版で別ライブラリによる行・画像・グラフ検証済みで、今回その生成処理は変更していません。

## 構成

- `index.html` / `style.css`：日本語の操作画面
- `app.js`：動画選択、範囲指定、抽出、結果表示
- `core.js`：AVI解析、透視補正、桁位置調整、7セグメント認識
- `presets.js`：提供4動画の表示範囲（温度値は含みません）
- `xlsx.js`：Excelと編集可能グラフの生成
- `vendor/jszip.min.js`：XLSXのZIPパッケージ生成（ライセンス同梱）
- `manifest.webmanifest` / `sw.js` / アイコン：PWA対応

依存ライブラリは同梱しており、CDNの読み込みはありません。サイトを更新するときは `sw.js` のCACHE名も変更してください。
